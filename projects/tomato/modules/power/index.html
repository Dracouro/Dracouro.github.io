电力系统

EU 记账 —— 谁在发电、谁在耗电、什么时候整舱停电，以及为什么「烧多少垃圾」是一个轻决策。

进行中C++数据表

为什么要一套独立的电力系统

因为火星上没有四季，也没有昼夜温差。舱内温度不是「环境给的」，而是 焚化炉烧垃圾产生的热与舱外 −60℃ 散热之间的动态平衡； 光照也不是太阳给的，是玩家自己拼出来的 LED 生长灯。

这两件事一旦成立，电力就不再是「随便插根线就行」的背景板， 而是主循环里唯一的能量入口：烧垃圾 → 有电 → 有温度 → 有光 → 植株能长。 所以它需要一本清晰的账。

记账的单位

写作 EU（Energy Unit），记账方式是每秒速率：

EU/s = EUPerSol ÷ SolSeconds，其中 SolSeconds = 120

120 是个换算常数，不是游戏计时器 —— 这条被特意写进了代码注释， 免得后来者看到「Sol」就以为要去做昼夜循环。物品那边用「每 Sol 耗多少 EU」描述， 运行时统一折成每秒速率，两套口径只在这一处换算。

结构

只有一个记账者，其余全是登记项 —— 这样每帧只需要把两个小 map 加起来， 永远不会去扫关卡里的设备：

发电与耗电

发电源（第 28 项「电力系统」在策划案里是新系统，工程里已经落地）：

类型 说明
Incinerator 焚化炉 烧垃圾产电产热，全游戏唯一的可控能量输入
SolarPanel 太阳能板 只产电，不产热；火星沙尘暴会让发电归零
NuclearBattery 核电池 稳定基载，代价是记账毒性（ToxicityDelta，尚未接线）
BatteryStorage 电池组 储能本体，电池容量 120 EU

耗电设备：LED / Humidifier / Fan / ChemistryStation / DripPump / Distiller / Sensor / CO2Generator 等。 设备分两类，判据就在数据表里一个字：

/** true = 按次扣费（TrySpendPower）；false = 持续负载（按 EU/s 积分） */
bool bPerUse = false;

持续负载（LED、通风扇、加湿头）会一直从净速率里扣； 按次负载（化学台一次反应 4 EU）走 TrySpendPowerFor 即时结算。 枚举里还预留了 Heater / Camera 几个位置，但按环境设定 「焚化炉是唯一热源」，加热器这条线在设计上已经被划掉 —— 看到枚举里有不代表它该被用起来。

焚化炉：一条把「物质」和「能量」接起来的路

燃料表 DT_IncineratorFuels 决定每件垃圾烧出多少电：

USTRUCT(BlueprintType)
struct FIncineratorFuelDef : public FTableRowBase
{
    FName FuelItemRowName;         // 烧的是 DT_Items 哪一行（唯一事实源）
    float EUYield = 0.0f;          // 烧完进电池多少 EU（锚点：1 根木条 = 10 EU）
    FName ByproductItemRowName;    // 副产物行名（木灰 / 木炭），None = 无
    float ToxicityDelta = 0.0f;    // 培育毒性增量（M4 先记账，未接毒性链）
};

副产物这一栏是设计上的关键：木条烧完出木灰，而木灰是钾肥的原料之一。 于是「烧掉换电」和「留着提炼」之间有了真实的取舍， 「物质 → 电力 → 生长」和「物质 → 养分」两条链也就此接上。

温度与光照：数值先定在原型里

这套环境模型先在 2D 概念原型里跑通并做过数值验证，再往工程里落：

项 模型
舱温 焚化炉供热 与 舱外 −60℃ 散热 的动态平衡（InitTemp 25 / HeatPerEU 0.8 / 散热系数 与 通风扇 ×5 散热）
理想区 18 ~ 28℃；越界开始扣生长倍率
光照 玩家自造的 LED 生长灯，档位给出 PPFD 值；PPFD < 150 生长 ×0.5，≥150 生长 ×1.5 并每秒有概率治愈病害

「烧多少」因此成了一个轻决策：1 根木条（10 EU）大约能扛 100 秒不跌出理想区； 但一次烧 100 EU 会把舱温冲到 100℃ 越过上限 —— 焚化炉 UI 会提前预警， 玩家于是学会了「分批烧」。燃烧不再是资源转换的仪式，而是温度管理的操作。

停电

CanOperate() 的判据是「供电够用 或 电池还有电」。 净速率为负且电池见底时整舱停电：所有持续负载设备一起停，化学台不启动， 直到电池回充到阈值才恢复。这个阈值存在的意义是防止抖动 —— 不然净速率为正负摇摆的时候，设备会以帧为单位疯狂开关。

#pragma once

#include "CoreMinimal.h"
#include "Engine/DataTable.h"
#include "Internationalization/Text.h"
#include "PowerTypes.generated.h"

// ------------------------------------------------------------------------
// Power (EU) system — shared enums & data-table row structs.
// EU is the fourth conservation chain. Accounting happens in "EU per second":
//   EU/s = EUPerSol / SolSeconds  (SolSeconds = 120 is a conversion constant,
//   not a game timer). See docs/电力系统_实施方案.md for the numeric anchor.
// ------------------------------------------------------------------------

/** Constant generation sources registered with the accounting component. */
UENUM(BlueprintType)
enum class EPowerSourceType : uint8
{
    None            UMETA(DisplayName = "None"),
    Incinerator     UMETA(DisplayName = "Incinerator"),
    NuclearBattery  UMETA(DisplayName = "Nuclear Battery"),
    SolarPanel      UMETA(DisplayName = "Solar Panel"),
    BatteryStorage  UMETA(DisplayName = "Battery Storage"),
};

/** Powered devices. Rate-type draw EUPerSol while active; per-use draw EUPerUse once. */
UENUM(BlueprintType)
enum class EPowerConsumerType : uint8
{
    None            UMETA(DisplayName = "None"),
    LED             UMETA(DisplayName = "LED"),
    Heater          UMETA(DisplayName = "Heater"),
    Humidifier      UMETA(DisplayName = "Humidifier"),
    Fan             UMETA(DisplayName = "Fan"),
    ChemistryStation UMETA(DisplayName = "Chemistry Station"),
    DripPump        UMETA(DisplayName = "Drip Pump"),
    Distiller       UMETA(DisplayName = "Distiller"),
    Sensor          UMETA(DisplayName = "Sensor"),
    Camera          UMETA(DisplayName = "Camera"),
    CO2Generator    UMETA(DisplayName = "CO2 Generator"),
};

/** Data-table row: per-device power cost. Row name matches the consumer type. */
USTRUCT(BlueprintType)
struct FPowerConsumerDef : public FTableRowBase
{
    GENERATED_BODY()

    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Power")
    EPowerConsumerType Type = EPowerConsumerType::None;

    /** Continuous load, EU per Sol (converted to EU/s by the accounting component). */
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Power")
    float EUPerSol = 0.0f;

    /** One-shot cost, EU per use. Used when bPerUse is true. */
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Power")
    float EUPerUse = 0.0f;

    /** true = per-use device (TrySpendPower); false = rate-type continuous load. */
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Power")
    bool bPerUse = false;

    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Power")
    FText DisplayName;
};

/** Data-table row: how much EU a fuel yields when incinerated. */
USTRUCT(BlueprintType)
struct FIncineratorFuelDef : public FTableRowBase
{
    GENERATED_BODY()

    /** DT_Items row name of the fuel consumed (single source of truth). */
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Power")
    FName FuelItemRowName = NAME_None;

    /** EU added to the battery when burned. Anchored to 1 wood stick = 10 EU. */
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Power")
    float EUYield = 0.0f;

    /** DT_Items row name of the byproduct (wood ash / charcoal). NAME_None = none. */
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Power")
    FName ByproductItemRowName = NAME_None;

    /** Cultivation toxicity delta. Logged in M4, not yet wired to the toxicity chain. */
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Power")
    float ToxicityDelta = 0.0f;
};

/** Read-only snapshot of the live power state (for UI / the conveyor director). */
USTRUCT(BlueprintType)
struct FPowerSnapshot
{
    GENERATED_BODY()

    UPROPERTY(BlueprintReadOnly, Category = "Power")
    float GenerationRate = 0.0f;

    UPROPERTY(BlueprintReadOnly, Category = "Power")
    float ConsumptionRate = 0.0f;

    UPROPERTY(BlueprintReadOnly, Category = "Power")
    float NetRate = 0.0f;

    UPROPERTY(BlueprintReadOnly, Category = "Power")
    float BatteryCharge = 0.0f;

    UPROPERTY(BlueprintReadOnly, Category = "Power")
    float BatteryCapacity = 0.0f;
};
